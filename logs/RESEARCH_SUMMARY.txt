🎯 KEY DISCOVERIES

1. WEB-FIRST ASSERTIONS
   • Eliminate flaky tests and race conditions
   • Auto-waiting until condition is met
   • Default 5s timeout (configurable)
   • No manual waits needed

2. TEST ISOLATION
   • BrowserContext per test (fresh profile)
   • Safe parallel execution
   • No test pollution
   • Proper resource cleanup

3. ROLE-BASED LOCATORS
   • Most resilient to DOM changes
   • Accessibility-first approach
   • Recommended order: role > label > placeholder > text > CSS
   • Better than XPath or CSS selectors

4. INTERNATIONALIZATION TESTING
   • Use real-world character sets (Chinese, emoji)
   • Catches encoding bugs early
   • Validates UTF-8 handling
   • Tests API consistency

5. FIXTURE-BASED SETUP/TEARDOWN
   • Clean, reusable infrastructure
   • Function vs module scope
   • autouse=True for automatic execution
   • Proper yield-based cleanup
